# Sfall Script Editor v5.0 (Rotators Build)
A script editor for the classic game Fallout 2. It allows you to edit and compile SSL scripts conveniently.

#### Features:
- Advanced SSL syntax highlighting
- SSL code tooltips for most built-in scripting functions, as well as user-defined procedures and variables
- Basic code auto-completion
- Browse all procedures and variables in the current script
- Some basic code editor features, like auto-indentation, selected-text indentation, etc.
- Quick view of MSG files associated with NPC/object scripts
- Quick compilation using an external command-line compiler
- Full support for advanced scripting using sfall (extended SSL language)

#### New Features:
- Code block completion for keywords if/ifel/elif/switch/while/for/foreach (by pressing the Tab key).
- Improved search through script code, with the option to highlight selected words.
- Syntax-error highlighting.
- Flowchart generation for visualizing node connections in the dialogue system, with the ability to edit nodes quickly.
- Dialogue preview, with basic testing available directly in the script editor.
- Interactive tree of all functions and macros used.
- Opening compiled scripts packed in Fallout DAT archives.
- Support for decompiling the associated .int files of Fallout 1/2 scripts.
